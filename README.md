
  # Scolar Admin Dashboard

  This is a code bundle for Scolar Admin Dashboard. The original project is available at Ashad Computer.

  ## Exécution (avec Bun)

  - Installer Bun : suivez les instructions sur https://bun.sh (ou utilisez le script d'installation officiel).
  - Installer les dépendances : `bun install`
  - Démarrer le serveur de développement : `bun run dev`

  Remarque : les scripts définis dans `package.json` restent valides. Si Bun n'est pas installé, vous pouvez toujours utiliser `npm install` puis `npm run dev`.
